# Atualização pelo navegador, sem instalar o Codex

Baixe `Salvar_Atualizacao_Rodovia_Studio.html` e abra o arquivo no Microsoft Edge ou Google Chrome do PC. A página usa a escolha de pasta do próprio navegador. Escolha `atualizacoes/` da instalação e depois clique em Gravar atualização.

O navegador concede acesso à pasta somente à página local, não ao assistente na nuvem. Ela consulta o canal estável deste repositório, baixa somente o ZIP correspondente, verifica SHA-256 antes da criação do arquivo e não substitui um ZIP de mesmo nome. Nenhum script do arquivo baixado é executado. Não há instalação de agente, serviço ou extensão, envio do conteúdo da pasta nem armazenamento persistente do identificador da pasta pela página.

A atualização em si continua a cargo do Rodovia Studio. Salve o trabalho antes de atualizar. A página não executa o aplicativo, não garante que um iniciador antigo esteja configurado para atualizar sozinho e não oferece controle remoto do Windows.

No Firefox/Safari ou se a política do computador bloquear a API de acesso ao sistema de arquivos, use o link de download manual e escolha a pasta no diálogo Salvar como. A página funciona com conexão à internet e usa apenas HTTPS do GitHub.
