# Rodovia Studio 2.67

Base: revisão 2.66 desta branch; não incorpora a revisão 2.65 externa.

## Uso

Em Cena → Mais ferramentas → Áreas e sinalização, use os ícones de zebrado branco ou amarelo. Também há comandos ZEBRADOBRANCO e ZEBRADOAMARELO. Marque o contorno e pressione Enter. Escolha cor, largura, intervalo livre e ângulo. Fluxo +45° / Fluxo −45° usam a orientação local de uma trajetória habilitada próxima; havendo direções ambíguas, informe o ângulo manualmente. Salvar e fechar confirma; Cancelar permite descartar o rascunho.

Para editar, abra Marcações → Zebrados → Configurar zebrado. Alterações usam o mesmo modelo salvo, histórico e atualização existentes. O espaçamento armazenado é entre centros (largura + intervalo livre). A amostra mostra a pintura dentro do polígono. O editor, vídeo e 3D usam barras métricas. Pintura não altera os cálculos ou desliga fluxos.

## Limites

O zebrado exige projeto de sinalização: a escolha branco/amarelo, inclinação e dimensões deve ser conferida pelo responsável técnico no MBST, volume IV. A consulta oficial foi bloqueada pela rede deste ambiente; não se declara conformidade normativa. Os valores iniciais mantêm os parâmetros ajustáveis anteriores (barra 0,45 m; centros 2,60 m), sem certificá-los como dimensões regulamentares universais. Não há dedução automática da cor a partir do DXF. Áreas existentes preservam os parâmetros anteriores até serem editadas.

A vista 3D também recebe a pintura preenchida da mesma geometria usada no vídeo, inclusive faixas de retenção. Não se substituiu o motor gráfico ou de tráfego. Não houve validação nativa Windows/Defender.

## Atualização

Feche o aplicativo e use o atualizador habitual. A atualização leve exige base 2.66 ou posterior; sem essa base, use o pacote completo. Preserve projetos, imagens e vídeos; rollback permanece disponível. Nunca substitua a pasta de dados por uma pasta vazia.
