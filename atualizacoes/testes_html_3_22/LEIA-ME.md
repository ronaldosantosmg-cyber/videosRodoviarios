# HTML separados para verificação — Rodovia Studio 3.22

Cada ZIP contém exatamente um arquivo, sem alterações, idêntico ao respectivo HTML do pacote completo 3.22. Os ZIPs não são pacotes de atualização: não têm manifesto do atualizador e não devem ser aplicados por ele.

Verifique primeiro o ZIP do index.html e depois o ZIP do ajuda.html, individualmente, com o antivírus atualizado. Informe o resultado de cada um e o nome da detecção. Não é necessário abrir/executar o HTML para verificar o ZIP. Se houver alerta, preserve a quarentena e não crie exclusões.

Os hashes e a comparação com o pacote completo conferem identidade/integridade, não ausência de malware. Não foi executado Microsoft Defender neste ambiente Linux. Não se declarou falso positivo nem remoção da ameaça.

O pacote completo 3.22 publicado continua com os mesmos HTML e pode reproduzir o alerta; a investigação ainda está pendente dos resultados individuais. Estes arquivos são para identificar a detecção, não para contorná-la.
