# Política de Segurança

## Alterações no código

O código oficial deve ser alterado somente por Pull Request revisado pelo proprietário do repositório.

- Não aceitar executáveis, scripts ou dependências de origem desconhecida.
- Não adicionar chaves, tokens, senhas ou credenciais ao repositório.
- Alterações em workflows, renderização, importadores e rotinas de atualização devem receber atenção especial.
- Pull Requests externos não devem receber segredos do repositório.

## Relato de vulnerabilidades

Não publique credenciais ou dados sensíveis em Issues públicas. Caso seja identificada uma falha de segurança, interrompa a distribuição da revisão afetada até a correção.
